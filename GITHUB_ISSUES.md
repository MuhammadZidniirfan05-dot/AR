# Indeks GitHub Issues & Alur Branch / PR (2 Model AI)

Seluruh GitHub Issues untuk **Fase 0 sampai Fase 9** telah diunggah ke repository **MuhammadZidniirfan05-dot/AR** dan disimpan di dalam folder `issues/` dengan aturan **Branch + Pull Request (PR)** menggunakan skema **2 Model**:
1. **Model Pekerja (Model Murah / Coder):** Membuat branch `fase-<N>-...`, mengerjakan tugas fase tersebut, commit, push, dan membuat PR ke `main` (**dilarang merge sendiri**).
2. **Model Reviewer (Model Mahal / Senior Reviewer):** Memeriksa `git diff main...fase-<N>-...`, mengaudit standar kode & *Acceptance Criteria*, lalu memutuskan **Approve & Merge** atau **Request Changes**.
